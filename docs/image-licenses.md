# Лицензии изображений

Каждое изображение на лендинге фиксируется здесь до публикации.

Правила:

- только лицензированные изображения с правом коммерческого использования;
- если лица узнаваемы — нужен model release (платные стоки с подтверждённым согласием);
- без знаменитостей, публичных персон, чужих логотипов и интерфейсов брендов;
- стоковые фото не выдаются за сотрудников Sparrow.Agency.
