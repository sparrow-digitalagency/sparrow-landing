# Статус текстов

Все тексты лежат в `src/messages/{en,uk,pl,ru}.json` — по одному файлу на язык, поэтому каждую версию можно править и утверждать отдельно. Набор ключей во всех файлах должен совпадать (`pnpm check:messages`).

| Ключ                                                         | Статус         | Примечание                                                                                                                             |
| ------------------------------------------------------------ | -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `hero.setup`, `hero.punchLead`, `hero.punchAccent`           | **Утверждено** | Основной оффер «Вашему бизнесу нужен не просто маркетинг. Ему нужна система.» (RU утверждён, UA / EN / PL приняты как рабочий вариант) |
| `sections.taskSelector.title`, `taskSelector.options.*` (RU) | **Утверждено** | Только RU                                                                                                                              |
| `hero.eyebrow`, `hero.subtitle`, `hero.tagline`              | Черновик       | На основе документа «Тексты сайта FINAL v3», адаптировано под 6 направлений лендинга                                                   |
| `hero.ctaPrimary`, `hero.ctaSecondary`, `common.ctaLead`     | Черновик       |                                                                                                                                        |
| `meta.*`, `nav.*`, `common.*`                                | Черновик       | Служебные подписи и SEO                                                                                                                |
| `hero.imageAlt`                                              | Пусто          | Заполняется вместе с финальной фотографией (сейчас временное декоративное изображение)                                                 |
| Значения `TODO(...)`                                         | Заглушки       | Тексты остальных блоков — PR 2.3                                                                                                       |

Правила: в основных текстах — полное название «Sparrow.Agency»; никаких вымышленных цифр, отзывов и результатов. Цифры — только подтверждённые, из опубликованных бенчмарков с источником или с пометкой «прогноз» и допущениями.
