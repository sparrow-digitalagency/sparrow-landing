# Sparrow Landing

Отдельный рекламный лендинг Sparrow.Agency (UA / EN / PL / RU).

Этот репозиторий не связан с основным корпоративным сайтом Sparrow.Agency и не вносит в него изменений.

- Стек: Next.js (App Router), TypeScript, Tailwind CSS, next-intl, pnpm.
- Разработка ведётся в отдельных ветках и попадает в `main` только через Pull Request.
